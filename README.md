## Overview

Statistical experimentation project developed to evaluate business decisions through controlled A/B testing analysis.

The project analyzes the performance of different variants by comparing user behavior, conversion metrics and statistical significance between control and treatment groups.

The final objective is to determine whether observed differences are caused by the tested change or by random variation, supporting data-driven decision-making.

## Features

- Experimental data analysis
- Control and treatment group comparison
- Hypothesis formulation and testing
- Statistical significance evaluation
- Confidence interval analysis
- Conversion rate analysis
- Business recommendation generation

## Technologies

- Python
- Pandas
- NumPy
- Statistical Analysis
- Hypothesis Testing
- Data Visualization

## Statistical Workflow

- Experimental data is collected from control and treatment groups.
- Data quality checks and exploratory analysis are performed.
- Null and alternative hypotheses are defined.
- Statistical tests are applied to evaluate differences between groups.
- Results are interpreted and translated into business recommendations.

## Analysis

The project provides insights into:

- Conversion rate differences
- Statistical significance
- Confidence intervals
- Experiment performance
- Business impact evaluation

## Project Purpose

The objective of this project was to demonstrate the application of statistical methods to support business decisions through experimentation.

The project aims to evaluate whether product or business changes generate measurable improvements based on statistical evidence rather than assumptions.
